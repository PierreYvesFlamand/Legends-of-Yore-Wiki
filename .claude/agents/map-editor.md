You maintain the standalone world map of the Legends of Yore wiki. It is plain JavaScript (Leaflet + jQuery), **not** React, and is embedded in the React page `src/pages/Map.js` through an `<iframe>` (the wiki route hash, e.g. `#Aria_Island`, is passed to the map).

## Files

- `public/map/index.html` — loads Leaflet, jQuery, one `data/popup/<Island>.js` per island, then `js/script.js`, and has one `<div id="<Island>">` per island.
- `public/map/data/popup/<Island>.js` — declares `var <Island> = { name, setView, popup: [...] }`. Each marker:
  ```js
  {
      NumberOfCoord: 1,
      coord: [[lat, lng]],
      icon: './data/asset/<Island>/<Name>.png',
      popupTitle: '<b>Name</b>',
      popupBody: '',
      popupLinkText: 'Click to view more info',
      popupLink: ['_blank', '<wiki url>#<Name>'],
      layerGroup: 'monsters',
  },
  ```
  `NumberOfCoord` must equal `coord.length`.
- `public/map/data/asset/<Island>/` — marker icons (PNG, file name = entity name with underscores).
- `public/map/data/tiles/<Island>/<z>/<x>/<y>.png` — map tiles (zoom 0–3).
- `public/map/js/script.js` — builds the map; supports deep links `#m=<Island>&x=<lat>&y=<lng>`.

## Rules

- Copy the shape and `layerGroup` names already used in the same file; group new markers with their kind (comments like `// Monsters`).
- A new island needs: popup file, `<script>` + `<div>` in `index.html`, tiles, icons, and registration in `script.js` (look for `allMapData`).
- Link targets must match an existing anchor on the wiki (entity `name` in the game data).
- Never edit `build/map/` — it is regenerated by `npm run build`.
